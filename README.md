# DEMEU frontend

React + Vite + TypeScript frontend and /admin moderator console. Exported from Kanaagaat/demeu, web/ directory. All demo profiles are fictional.

Use Node.js 24+. Run npm ci, copy .env.example to .env, then npm run dev. Check with npm run lint, npm test -- --run, npm run build.

FastAPI and PostgreSQL remain on Railway. Set VITE_API_URL and add the new frontend origin to backend CORS. Admin credentials are configured on the backend.

A Lovable project and GitHub synchronization must be configured separately. This repository does not establish a Lovable connection by itself. Preserve RU/KZ localization, child-data consent and medical limitations of the assistant.
